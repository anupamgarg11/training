## The sequence, not the weekday

Always in order; the rest day floats to wherever the week allows.

1. Run — tempo or intervals
2. Legs + Core
3. Easy run
4. Shoulders + Arms
5. Long run
6. Chest + Back
7. Rest (floats)

Only two runs available? Drop S3. Only one? It's S5, the long run, always.

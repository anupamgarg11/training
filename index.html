The sequence, not the weekday

Always in order. The rest day floats to wherever your week allows.

  1. Run — tempo or intervals
  2. Legs + Core
  3. Easy run
  4. Shoulders + Arms
  5. Long run
  6. Chest + Back
  7. Rest — floats

Only two runs this week? Drop S3, the easy run. Only one? It's S5, the long run, always. Never let the long run stall.
Short on a lift? Drop sets across the board, never whole exercises — you lose less that way.
